# Contributing to slack-grammar

Thank you for your interest! This project is currently **not accepting
external contributions** — pull requests from non-collaborators are blocked by
a repository interaction limit, and this is deliberate: it is a personal
project with a single maintainer and no review bandwidth.

## What you can still do

- **Security issues**: report privately via GitHub's "Report a vulnerability"
  (Security tab) — see [SECURITY.md](SECURITY.md). This channel stays open.
- **Bug reports and ideas**: email the maintainer (see GitHub profile).
  Include: Slack version, GPU/driver (`vulkaninfo --summary`),
  `slack-grammar doctor` output, and a synthetic example sentence.
  **Never paste real messages from your workspace.**

## If that ever changes

The [README](README.md) support section will say so. The ground rules that
contributions would follow are documented in [AGENTS.md](AGENTS.md) (privacy,
never eat the user's text, never break Slack, permissive deps only) — reading
it is still the fastest way to understand the codebase.
