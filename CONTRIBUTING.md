# Contributing to slack-grammar

Thank you for your interest! This project is currently **not accepting
external code contributions** — pull requests are disabled at the repository
level (a native GitHub setting, see the [README](README.md) support section).

## What you can do

- **Issue reports**: welcome from anyone — Slack version, GPU/driver
  (`vulkaninfo --summary`), `slack-grammar doctor` output, and a synthetic
  example sentence. **Never paste real messages from your workspace.**
- **Security issues**: report privately via GitHub's "Report a vulnerability"
  (Security tab) — see [SECURITY.md](SECURITY.md).

## For agents and humans exploring the codebase

[AGENTS.md](AGENTS.md) documents the working rules (privacy, never eat the
user's text, never break Slack, permissive deps only) and is the fastest way
to understand the project. `https://gitmcp.io/timrichardson/slack-grammar`
serves this repo as an MCP server for AI tools that want structured context.
