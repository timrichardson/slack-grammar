# Code of Conduct

## Our pledge

Everyone participating in this project — issues, PRs, discussions, chat — is
expected to be respectful and constructive. Harassment of any kind is not
tolerated.

## Standards

**Encouraged:** kind, patient communication; clear bug reports; questions
are welcome; effort over expertise.

**Not acceptable:** harassment, demeaning comments, publishing others'
private information, any conduct a reasonable person would consider
unprofessional in a shared workspace.

## Enforcement

Violations: report via GitHub private vulnerability reporting (Security tab)
or email the maintainer. Reported incidents are reviewed at the maintainer's
discretion; consequences range from a warning to a permanent ban.

This is a minimal, common-sense codification rather than a long legal
document. If you're unsure whether something is appropriate, don't do it.

## Attribution

This code of conduct is adapted from common open-source practice
(cf. Contributor Covenant, which this project simplifies).
